## 四、句子级改法（**待四席齐后一次落笔**）

1. **§3 标题**「它必然失败」→「**它会让权威变成三份**」；正文补一句区分：**点对点翻译（要反）** vs **单向投影（定稿承认保留）**——即"我们反的是**多处权威**，不是一切翻译"。
2. **§一 / §二 首句**改量词：**"不是没有说法，是有三份互不承认的说法。"**
3. **§4.2 开头**先给"共同"的三条判据（唯一权威 / 可核对 / 多方可达），**并给检验方式**：
   > **检验**：任取一方说出的一件事，另外两方都能在**不问它**的情况下，从同一份记录里找出**同一件事**。
4. **§4.2 的"语义"四项 → 七项**（补全序与时间基准 / 身份与权限绑定 / 可逆性 / 单位量纲 / 指称可解析），并把"不读文档也能懂"降为**目标**而非判据。
5. **§4.3** 把"所以意义必须由它自己承担"改为"**在它之外没有各方都承认的解释者**"。
6. **新增一节**「**为什么恰好这三件：与五种替代方案逐一对表**」（①三方直连 ②统一中间语言 ③共享词汇表＋局部翻译＋多份本地真相 ④单一事件流＋无投影 ⑤本方案；列＝能否独立核对 / 谁裁定冲突 / 规模成本 / 被哪条边界限制）。
7. **删 §五**（纪律并入 §4.2）；**§八 收束句重写**（把目的放回主句，手段降为从句）。
8. **补一次术语换名登记**：「底座 + N 投影」→「**世界**」（H-3）。
