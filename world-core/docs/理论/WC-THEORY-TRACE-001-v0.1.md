# `WC-THEORY-TRACE-001-v0.1` · **理念↔代码 逐条核验台账**

> **本件是什么**：把理论原文里**能判真假**的主张**逐条抽出来**，每一条给出"**理论原文 / 我的实测 / 核验结论 / 判据**"。
> **用途**：① 给评审专家当底盘（他们不必自己去代码里翻）；② 支撑《语义世界》理论书的"为什么现在不行、我们做到哪一步"两章。
> **纪律**：**凡我没实测过的，一律标 `未核实`，不写成结论**；凡属我的推断，标 `（推断）`。
> **四态**：`✅ 已落实` / `⚠️ 半落实` / `❌ 未落实` / `✂️ 不归代码管`（理论已声明它不由代码承担）。
> **取数时点**：提交 `f4f9591`；环境 `Linux 7.2.6-arch2-1` / `rustc 1.98.1`。
