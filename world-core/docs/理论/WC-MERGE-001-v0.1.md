```text
    WC-PREFACE-001-v0.1 … -v0.7（序的历次形态）
```

> **体例（v0.8 起）**：**正文只叙述这件事本身**（无版本号、无自我说明、无附录交叉引用）；
> **编号、版本、评审处置、实测记录、签字栏一律在记录件里**。这不是形式问题：
> 把修订过程写进正文，读者读到的就不是这件事，而是我们改稿的过程。

> **合订件（转化物·不进 git）**：序 v0.6 ＋ 全书一至四章 → `D:\Code\book-build\语义世界-理论书-第一版-合订.md`
> （**源件一改即作废，需重新生成**；生成规则与两个源件的 SHA256 写在文件头）。

> **一条铁律**：**第 5 层的文件不删除**，只标注"史料 ＋ 取代理由"。这与本项目既有的"被取代的说法不删除"处置一致。
