## 九、本记录**不能**当什么用

1. **不能当"独立评审"的证据**：两席由**同一个执行者**派出、核对、归档，**签字栏全空**；**独立性来自分了席，不来自分了人**。
2. **不能当"专家已复核我的处置"**：两席回件中**无一份读到 v0.4**，处置是我方立的。
3. **本记录的"采纳"只表示"已落笔"**，不表示"已成立"：序 v0.4 §7.3 列出的红项**不因本轮落笔而变绿**。
4. **行号一律以"按 `\\n` 切分"为准**（`read` 工具／`ReadAllLines`／Python `readlines`）；**Windows 上的 pwsh `Get-Content` 会按 ANSI 解码、行数偏小**（实测同一文件 147 vs 180；序 v0.4 为 338 vs 425 的量级差），**以行号作证据者禁用之**。
5. **本轮的实测只在 VM 内、只对 debug 构建、只用了一个非 root 身份（`agent` uid 1001）**；**未做**多身份矩阵、未做 release 构建对照、未做 Landlock/seccomp 形态。
