## 九、本记录**不能**当什么用（自我约束）

1. **本记录不能当"独立评审"的证据**：四席由**同一个执行者**派出、核对、归档，**签字栏全空**；**独立性来自分了席，不来自分了人**。
2. **本记录不能代替作者对内容的判断**：处置是我方立的，**专家未复核我的处置**——四席回件中**无一份读到本记录的处置结果**。
3. **本记录中的"采纳"只表示"已落笔"**，不表示"已成立"：v0.3 里**B-3／B-4／B-5／B-6／B-8 五条检验今天都是红项或未采集项**，登记在 §7.2，**不因"已落笔"而变绿**。
4. **本记录的行号一律以"按 `\n` 切分"为准**（等同于 `read` 工具、`[System.IO.File]::ReadAllLines`、Python `readlines`）。
   **本轮实测到一处工具陷阱，登记在此以免后人踩**：在 Windows 上的 pwsh 里执行 `Get-Content <本目录的 UTF-8 文件>` 会**按 ANSI 代码页解码**，
   多字节序列被吞并后**行数会偏小**（实测同一份文件：`Get-Content` 计 **147** 行，`ReadAllLines` 计 **180** 行；序 v0.3 分别为 **338** 与 **425**）。
   ⇒ **凡在本项目里以行号作证据，禁用 `Get-Content` 计数**：一个错的行号会让"逐字可查"变成"查不到"，而**查不到与没写，在本项目的判据里是不同的两件事**。
