## 四、**必要性的合并结论**（本轮最重要的产出）

| 项 | 席 U | 席 S |
|---|---|---|
| 判决 | **可干可不干** | **不必干** |
| 决定性理由 | 收益侧**不存在可计算的单位**（收益投资比 0÷0、回收期无定义、收益项全 ¥0 或不可估算），成本侧却已算到 3.4 人日/月、接手 25–40 人日 | **必要性这一侧交白卷**；未被建立的必要性默认是不做 |

| 建议 | 先花 **1.5 人日**（两周时间日记＋一页记分牌）把"不干"量出来；**停在做完台阶③（5–8 人日）然后停** | 见六条改口条件 |

**两位专家没有一位判"必须干"。** 七席里其余五席（P／Q／R／T／V）无一为"必须干"提供支持性结论；席 T 明确判"截图那条不能当必要性证据"。

**七席共同指向的三件事**：
1. **全部九条检验都是"对内判据"**（席 U）：没有一条在"不干"的世界里会变红 ⇒ **有成本会计，没有收益会计；有验收判据，没有反事实判据**（记录件 §九）。
2. **可辩护的增量被压缩到"一格"**（席 S 引席 G）：相对 git 的增量只有语义本体／门禁／因果链三样，而**本体今天不校验**（本轮 VM 实测：未声明的实体与字段 `rc=0` 照收）、**门禁在单机形态下退化为约定**、**可逆性被接反** ⇒ 真实增量只剩**因果链**，而它可由 2–2.5 人日的 trace_id 路线拿到（席 U）。
3. **本仓自己有现成供应商**（席 S）：读侧无闸门＝Confluent 的一个配置项；摘要链无密钥＝journald 的 FSS（而实现用的是 FNV-1a 64 位非加密哈希）；K8s Admission Webhook／OTel 语义约定／OPA／Sigstore"都是可问责性这一层的现成供应商——它们只是没有把它叫世界核心"。

**记录人的处置（不代签，仅供裁决）**：
- **在"要不要继续投台阶④⑤"上，席 S 的默认成立**：未举证必要，不投。
- **在"已经做出来的东西怎么办"上，席 U 的判决成立**：做到台阶③（止损，5–8 人日）然后停，并把席 T 的"出口注册表 ＋ 投递面 ＋ 入向"列为第一优先。
