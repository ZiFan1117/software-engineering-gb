# 第三章 · 为什么必须由共同的一层承担

> **因为跨过一条边界，谁也没有资格替对方说"你理解错了"。**

## 3.1 多方同时在场时，意思只能由共同依赖的那一层承担

前提有两句，各自挡掉一条退路。

第一句是"多方同时在场"。参与方不止一个，而且同时活着、同时要用到同一件事。这一句挡掉的是"事后再说"：如果各方不同时在场，意思可以由先写下来的一方留在那里，后读到的一方补上，承载这件事的位置可以由时间差顶过去。同时在场意味着每一次交汇都要当场成立，谁也没有时间等一份约定慢慢谈成。

"同时在场"说的是同一件事上同时有不止一方要用到它，钟表上差多久不作数。一方今天用、另一方三个月以后才用，那还是"事后再说"的路子，前提不成立，命题也不表态。

第二句是"各方只需要向对方交代这件事是什么意思"。这一句给这条命题划射程。它管的是意思这一格，不管"该不该做"；后者要的是有权力的机构，一处承载位置解决不了它。射程划准了，命题才不会被"我们上面有主管""我们有仲裁人"这类情形误伤。

两句之外还有一条，不必单说也成立：各方之间没有一方天然说了算。若一方本来就是各方承认的上级，那类情形不在这一句的射程里。

**命题**：这种时候，"同一件事是什么意思"只能由各方共同依赖的那一层承担。

这个"只能"说的是位置上的唯一。承担这件事的地方，必须是各方都已经依赖的、位于各方之外的那一处。

"承担"在这里有确切所指：一件事是什么意思，由那一处说了算。各方不必各自留一份自己的版本，也不必每次见面先确认一遍"我们说的是不是同一件事"。反过来看，如果每一处交界都要现谈一次、谈完就散，就说明还没有哪一处承担着它。

"共同依赖"也是可以看的：各方是不是照着它说话；离了它，各方还对得上吗；换掉它，要不要各方各改一遍。三条里有一条不成立，它就算不上各方共同依赖的那一处。

命题先落在承载上，判定跟着来。意思有了共同的一处，争执才有落点；没有那一处，争执只能停在两方各自的说法上。

命题不给形态。那一处是库、是协议，还是别的东西，不在这一句里。命题也不谈内容：它不说那一处装什么话、留几格。

命题的射程与参与方是谁无关。人对人、agent 对机器、设备对设备，只要来源不同、又同时在场，都在这一句的射程里。

命题可以被推翻。只要找到一例：多方来源不同、同时在场，而"这件事是什么意思"由其中一方单独承担，其余各方也都认，这一句就不成立。

前提里那三条都能观察：参与方有几个、是不是同时在用同一件事、各方之间有没有一方是上级。前提不成立的时候，这一句不表态。

> **一句话**：这种情形下，意思只能落在各方共同依赖的那一处。

## 3.2 什么情况下这一层不必要

命题靠三条理由立住。三条说的是同一件事：跨过那条边界之后，参与方手里的东西不够用了。

第一条，跨过边界，任何一方都没有资格替对方说"你理解错了"。资格不是自己发给自己就有的，它要对方承认。一方被承认的范围，只到它自己那一侧的说法为止。越过那条界，它的话照样算数，但只能算它那一方的说法，算不了"这件事是什么"。

第二条，任何一方都不能只凭自己证明"我们说的是同一件事"。它能拿出来的凭据，是自己那一份说法，加上自己那套读法；用自己的读法读自己的说法，永远自洽，也就证明不了什么。要证明两方说的是同一件事，需要一份不属于任何一方的对照。

第三条，没有任何一处可以说"以我为准"。分歧发生在两方之间，裁定需要一处不在这两方之列的位置；而各方都在当事人之列。这一处只能由各方共同依赖的那一层来当。同一句话经两条路径处理，可能得到两个结果，两处各自都自洽，谁也没有资格把对方那份判为错。

把这三条反过来读，边界的画法就出来了：它们同时失效的条件只有一个，各方本来就共享同一套来源。这时意思不由各方各自产生，跨过交界也不会长出"你理解错了"。

三种情形：同一份规范、同一批人、同一个出厂设定。

最干净的是同一份规范。一份规范交给同一套校验，符号的含义在程序之外就已经定死，写的人和读的人都没有各自解释的余地。同一批人靠的是当场能校正：说岔了，两句话就能对上。同一个出厂设定靠的是各方本来就出自一份设定，谁都没有自己的版本。

失效条件自己也带条件。同一份规范要真成立，得各方照同一版实现：规范改了一版而有一方没跟上，来源就分成两套。同一批人要真成立，得人还在、还同时在场：人换了、走了，共享的那一套理解跟着走。同一个出厂设定要真成立，得版本一致：一台升了级、另一台没升，设定就分成两份。三种情形都靠"同一套来源"活着，而来源会漂移。

于是失效条件可以写得很短：各方共享同一套来源时，这一层不必要。

这个条件可以观察。交接之后各方不需要再谈一次，说明来源确实同一套；每一次交界都要新谈一份约定、谈完就散，说明来源不同，这一层就是必要的。

还有一条要划清：失效条件成立，只说明这一层不必要，不说明分歧不会发生。那种情形下的分歧在那个共享来源内部解决，与这一层无关。

> **一句话**：只有各方共用同一套来源时，才不需要这一层。

## 3.3 这一条今天有几分分量

本项目不适用于失效条件。要接进来的是人、agent、设备，三方的来源各不相同，也没有哪一份规范由三方共用。所以在这一侧，命题成立，边界不在这里。

这一句要先对本书自己说一遍。前提那一句是"多方同时在场"，指的是同一件事上同时有不止一方要用到它。本项目声明的形态是一个操作者、一台机器、一个世界：第二个执行者不会出现。一件事上同时要用到它的，今天只有一个操作者。⇒ **这条命题的前提，在今天的形态里不成立。**按这条命题自己写下的规矩，前提不成立的时候，这一句不表态。**本书最强的那条论证，在今天这个形态里处于不表态状态。**这件事写在这里，是因为它是可核的事实，也是按本书自己的规矩必须写下来的一条。

这类情形的出路不由这一句管。今天可以核的只有一件事：这一层无论由谁承担，它给出去的都必须是一份与各方来源无关的对照。

还有一路替代方案要正面处理：**多方共用、定期同步、共同维护的规范。**它不是某一家单独发布的，也不是某一方临时的约定：各方共同签署，按期改版，改版时各方一起同步。这一路如果成立，它看上去正好就是"各方共同依赖、又位于各方之外的那一处"，这一句的分量要跟着掉一截。

命题这一侧今天挡不住它，如实写下来：三条理由说的是"意思不能由某一方单独承担"，这一路本来就不是某一方单独承担。它今天唯一能被压住的地方在第三条：规范文本遇到没预见到的事、或者同一段文本有两种讲得通的读法时，文本自己不会开口，得有一处不在这几方之列的位置给出判定；而这一路把解释权留给谁，没有写下来。这一处就是今天挡不住它的地方——**这一条今天挡不住"多方共用的规范"这一路，得记下来。**

> **一句话**：这一条今天不表态，也挡不住多方共用的规范。
