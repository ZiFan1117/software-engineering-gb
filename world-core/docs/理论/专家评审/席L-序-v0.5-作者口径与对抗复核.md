### C. 细节一：v0.5 有没有把「共同的说法」与「共同的表达方式」分开对待？

**没有。** 而且不分开的后果不是中性的，它撞上了本项目自己的原文：

- `WC-BOOK-001-v0.1.md` **L112**（逐字）：「所以"共同"**不等于**"同一份表达"，而是：**同一个底座 + 各按各自最优的方式取**」
- `WC-BOOK-001-v0.1.md` **L105-107**（逐字）：「**⚠️ 但这里有一条必须说死的界线**（否则"共同的东西"这三个字会被误读成另一种翻译）：」／「> **"共同的东西"不是"一种大家都得学的新中间语言"。**」
- v0.5 §4.0 **L187**（逐字）：「| **语义系统** | **连上它的那些东西**：人用的语义系统、AI agent、设备的驱动与适配器——它们**说的是语义事件，不是自己的方言** | **对齐者，不是被造物** |」

⇒ 「说的是语义事件，不是自己的方言」＝ 要求各方改用同一种**表达形式**，这正是 BOOK L112 逐字否掉的"同一份表达"。**这是我的推断**：作者原话里"共同的说法"与"共同的表达方式"两项**强度不同**（前者是语义内容对齐，后者若读作"同一份表达"就与本项目的反中间语言立场冲突），v0.5 把两者压成一格之后，只能写出最强的那一种读法，于是 §4.0 L187 与 §4.1 L195-196（「**不是"一种三方都懂的新中间语言"**——那又回到 §3.2 的天花板（求交集 ⇒ 只剩最弱那一层）」）在**同一份文件里 8 行之内互相拆台**。

**原文里有一条现成的分界线，v0.5 没有用**：`00-总纲.md` **L167**（逐字）：「- **边界（判据一句话）**：**进口货物可以，进口法律不行**——世界可以买算力、可以翻译旧网页，」（并见 L173「其输出必须**翻译成世界 schema**」）。按这条线，"共同"的是**法律／说法**，不共同的是**货物／内部表达**——这正好能把作者并列的两项分开。v0.5 全篇未出现"进口货物可以，进口法律不行"。

### D. 细节二：§6.2 选了哪一种读法？是否可能不是作者本意？

**（1）作者那句的主语链确实有歧义。** 逐字：

> 「……**机器也是**，**人通过投影**，就是语言投影或者什么投影，然后呢，**也能够和这个语义系统进行交互**。」

至少两种读法：

- **读法甲**：「这个语义系统」＝ 前面被点到的"语义系统或 Agent"这一类**接入者**（＝ v0.5 §4.0 L187 的定义）。
- **读法乙**：「这个语义系统」＝ 作者句首的"我们的总线或者是语义事件"那一层**共同的东西**（＝ v0.5 的"语义世界"）。

**（2）v0.5 §6.2 选了甲。** 证据是它的表把"语义系统"与"AI agent"并作一行（L354 行首逐字：「| **AI agent／语义系统** |」），而把"人"单列并限定为**只读**（L355 逐字：「| **人** | 只读**给人看的那一份**出口 | 不算：人经**投影** |」）。若取乙，"人经投影"的落点应当是**世界**，而不是某一类接入者；v0.5 L358-361 的收束句（「**三者对齐的是同一份事实——不是同一张界面。**」）实际写的是乙的意思，但它的表用的是甲的分类。

**（3）我的判断：这个选择很可能不是作者的本意。这是我的推断，理由三条：**

1. **对照结构**：作者把「机器也是」与「人通过投影……也能够和这个语义系统进行交互」并置，前两项（语义系统/Agent、机器）的主语都是**接入者**，若第三项主语突然变成"接入者之间的交互"，句子的对照结构断裂。取读法乙时三项一致：**三类东西都接到同一层**（前两类"直接"，人"经投影"）。
2. **收束句**：作者的原话以「统一他们的底层的**这个世界**」收尾——"这个世界"是被接入的**对象**，不是接入者。作者随后确认的两个术语之一"语义世界"正是这个对象；若"这个语义系统"指接入者，则收束句里的"这个世界"在句中**无处安放**。
3. **取甲会撞上作者自己的第一句**：甲读作"人经投影与语义系统（＝agent）交互"，那正是作者开头要破坏的「人 ←→ 翻译 ←→ agent」那条边。v0.5 只能靠把"人"写成**只读**来避免这条边变成双向——代价是人失去了写路径，而 §六 L336 又逐字写着人「他自己**也在写事件**」。**同一份文件的两节互相否证**：
   - §六 L336（逐字）：「**人的位置不是"agent 的前端"**：他自己**也在写事件**（他要做什么、他批准了什么、他**否决**了什么）」
   - §6.2 L355（逐字）：「**人** | **只读**给人看的那一份出口」

**（4）建议处置（本席只提，不代改）**：① §4.0 L187 的"语义系统"定义与该句的所指分开；② §6.2 补一行"人：**写**经投影入口（界面操作 → 译成事件）；**读**经视觉出口"，与 §六 L336 对齐；③ 把作者原话的这处歧义如实登记为 §九 待裁决项（v0.5 L462-468 现无此项）。

## 三、Q3 攻击"三分"

### A. c 真的是 a 与 b 的分界吗？

**分两步判。**

**第一步：c 是不是被原文证伪的那个"中间语言"的另一种说法？——这一半我打不倒。**

原文对"中间语言"的证伪打击的是**求交集的单一格式**：`00-理论定稿` **L185**（逐字）：「**中间点是求交集，交集必然小于全集。**」；`WC-BOOK-001-v0.1.md` **L107-112**（逐字）：「**"共同的东西"不是"一种大家都得学的新中间语言"。** …… 所以"共同"**不等于**"同一份表达"，而是：**同一个底座 + 各按各自最优的方式取**」。而 c 恰恰是原文给出的**替代物**（`00-理论定稿` L190「真相层：语义总线（一份数据…）」）。所以"c＝中间语言"这个等式在原文里**被明确拒绝过**，本席不能据此打倒 c。

**第二步：但 v0.5 对 c 的措辞，把 c 写成了"同一份表达"，这一半打倒。**

- v0.5 §4.0 **L187**（逐字）：「它们**说的是语义事件，不是自己的方言**」
- v0.5 §4.0 **L189**（逐字）：「**语义系统之间不互相谈，各自跟语义世界对齐；对齐用的通货是语义事件。**」

「说的是语义事件」「对齐用的通货是语义事件」——**把 c 从"对齐的真相层"改写成了"各方共用的表达形式"**。而"共同≠同一份表达"是 BOOK L112 逐字写下的界线、v0.5 §4.1 L195-196 又重述了一遍（「不是"一种三方都懂的新中间语言"」）。⇒ **c 不是中间语言；v0.5 §4.0 对 c 的这两句是。** 这是我的推断，但两句原文与两句 v0.5 逐字并置即成立。

**第三步（三分表不完备：没有"写"这一格）——这一条是硬伤。**

三分把 a（两两路由）、b（单向投影）、c（底层共同说法）列全，但 v0.5 自己的 §六 里有一类动作**三格都放不进去**：

- §六 **L339**（逐字）：「| **驱动／适配器的作者** | 把一件事**翻译**成"一种写法" | 同一份记录 | **这是一切的前提**——没人写它，账本是空的 |」
- §六 **L336**（逐字）：人「他自己**也在写事件**」
- `2-依据/15` **L186**（逐字）：「| **人** | 在界面上操作 → **翻译**成 `act` | **视觉投影** |」；`WC-BOOK-001-v0.1.md` **L220** 同句。

"把一件事写成世界的那一种写法"——**它不是 a**（不是两两各谈一份），**不是 b**（b 的定义是"从同一份真相出发、单向译成人/程序看的样子"，是**读侧**），**也不是 c**（c 是底座，不是写进底座的动作）。三分表里没有这一格。而 v0.5 §3.0 L126 立的用语纪律（「**本序此后不用"翻译"指代 b，一律叫"投影／出口"**」）只覆盖 a/b 两侧，**对写侧不作规定**——于是 §6.2 只能临时另造一个判据（L354「**算**：它不必为每一对交界单独谈一份约定」）来安置写侧，这就是 §6.2 与 §4.0 打架的根源（见 C）。

⇒ **（a）的判定：c 不是 a 与 b 的分界吗？——是，原文支持；但 v0.5 没有用 c 去分辨任何一对具体的东西，它只用 c 宣布了 a/b 的分界，而真正需要分辨的是"写侧"（写进共同说法 vs 两两谈），三分表在这一侧是空的。**

### B. §3.0 L126 的用语纪律与既有文档是否一致？

**不一致，而且三重不一致。**

**（1）既有全套文档里"翻译"这个词的用法（逐字＋行号）：**

**（2）v0.5 自己在 39 行之后违反了这条纪律：**

### C. §4.0 L187 的"语义系统"定义与既有"三方／各方"划分是否冲突？

**（1）先说一个事实核查**：本席对全仓库 `*.md` 检索 `语义世界|语义系统`，**"语义系统"除 v0.5／v0.6 外零命中**——即它是**本序新造词**，四份指定原文里没有按这个词做过的划分，故不存在"与既有'三方'划分冲突"的直接对照（v0.6 L29 亦自承"「语义系统」为本序新造词（全库零命中）"，与本席检索一致）。

**（2）但冲突在 v0.5 内部，两处：**

**冲突一（不需要推断，逐字即成立）：** §4.0 **L187** 的定义把「**设备的驱动与适配器**」列为语义系统；§6.2 **L354** 的行首把"语义系统"**整体**判为"算直连"；而 §6.2 **L356** 又把"机器／设备"判为「由**驱动**代它写"我做了什么"，读"要我做什么" | **不算：机器经**驱动 ＋ 投影」。

**冲突二（推断）：** §一 **L87-88**（逐字）：「**"三方"是能力档位，不是三类人。** 同一时间点上，一个人可以同时占三个位置（他自己在操作、他用的 agent 在请求、他家的设备在写）。⇒ 本序下文一律用"**各方**"」——而 §4.0 L187 的定义项写的是「**人用的语义系统**」。**"人用的语义系统"落在 §6.2 的哪一行？** 若它是"语义系统"（第一行），则人在使用它时**算直连**，与 L355"人……不算：人经投影"冲突；若它属于"人"那一行，则 §4.0 L187 就没有把"人"与"人用的语义系统"分开，而 §6.2 的三行二分法要求每个主体**必落一格**。**这是我的推断**：L187 的定义含混（既不是"人不算语义系统"，也没说"人用的语义系统"是独立主体），导致 §6.2 的表在"人"这一格上不完备——**v0.5 全文没有一句写"人不算语义系统"**（v0.6 补了这句，见 §六 3）。

## 四、Q4：v0.5 是把上一轮的修正撤回了，还是在保留内核的前提下重新表述？

**代价（不是"反悔"，但是净退让，且退让是付给这一条线的）：**

1. 被删的是那句**安抚性的许可**（"不是'翻译'这个动作"）。它换成了 §3.0 L126 的**用语纪律**，而这条纪律**三处都没兑现**：v0.5 自己不守（L165／L167）、既有文档不守（`00-理论定稿` L201 把单向译法仍叫"翻译"）、附录 D 不登记（违背 §九 L460）。
