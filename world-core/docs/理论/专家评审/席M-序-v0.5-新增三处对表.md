## 四、Q4 一条硬问题

> **问题**：v0.5 §3.0 的核心断言是「**有 c，转译才是单向投影；没有 c，转译就只能是两两路由**」。这句话在既有理论里有没有被正面论证过？若没有，它是本序第一个把 a／b／c 三者串成因果链的地方——那么这个因果链是"显然成立"还是"需要论证"？

### 4.1 前半句：**有正面依据**（且是本条唯一有据的一半）

- `00-理论定稿.md` L201 逐字：
  > 「**损耗**：从"三方两两互译"降为"底座 → 人的投影"——**翻译只发生在一个方向上，且从同一真相出发**。」
- `06-协作与承载.md` L119 逐字：
  > 「底座模型：翻译只发生在"底座→人的两个投影"，2 次、**单向**、机械、**从同一真相出发**」

⇒ 原文把"单向"的**条件**明确写成"**从同一真相出发**"；而"唯一真相"在 `14` L104／`15` L152 里就是语义事件账本（＝c）。
**所以"有 c ⇒ 单向投影"是被正面写过的**（判 ✅，见 N-13）。

### 4.2 后半句：**既有理论里没有一处正面论证过**

- **评审侧**：该蕴含在一份既有独立评审里被**复述过**——`WC-PREFACE-TRACE-002` 之外的 `席I-序-首席怀疑者独立评审.md` L90 逐字：
  > 「\| ① 语义事件 + ③ 出口 \| ② 账本 \| **不成立**。这是一份**共享的 schema/格式规范 + 各方自己的渲染器**——但**没有唯一交汇点**，权威无处安放 ⇒ **回到翻译器路线**（本席承认**会退化成标准**，**但"标准"恰恰是序拒绝承认的第三方选项**，见攻击 2） \| 序在此处"对"，但**只对在它自己的定义里** \|」

  ⇒ 它在那里是**复述＋两个限定**（"会退化成标准"／"只对在它自己的定义里"），**不是论证**。
  ⚠️ 时间与文本两处可核事实：该文件 mtime **18:48:38**，v0.5 mtime **19:15:28**（相差约 27 分钟）；"回到翻译器路线"与 v0.5 的"只能是两两路由"**措辞同族**。**这是我的推断**：§3.0-c 的后半与席I 那一格同源；本席**无法证明**作者读过它，此处只登记可核的对应关系。

### 4.3 它是"显然成立"还是"需要论证"？

**答：需要论证，而且现在这个写法（"只能"）在本序自己的文本里就已经被反例打掉。**

**理由一（逻辑形式）**：这是一个**穷尽性断言**——它主张"转译只有两种形态"：有 c 的单向投影 / 无 c 的两两路由。穷尽性断言**不能**由"a 坏、b 好"的对比自动得到，它必须**排除第三种可能**。举证责任在主张者。

**理由二（本序自己摆出了第三种，且在 §3.0 的下一节）**：v0.5 §3.2 L146-147 逐字：
> 「现实中人们并不两两写翻译器，而是**约定一个中间标准**：HTTP 头、JSON、ISO 8601、SMTP、`Content-Type`、OAuth、OpenAPI、Protobuf。
> 参与者从 3 增到 10，**新增的是适配器（线性），不是互译对（平方）**。**它们确实管用**——这必须承认，否则就是自欺。」

这个形态**既没有 c（没有一套语义事件＋一本只追加的账），也不是两两路由**（增长是线性的适配器，不是平方的互译对）。⇒ 除非把"转译"**定义**为"点对点的两两翻译器"，否则 §3.0-c 的后半**被本序 §3.2 直接证伪**。
**处置建议（本席认为最小改动）**：把该格改成**定义性区分**而非**因果必然后果**——例如"a 与 b 的分界在 c：**同一份真相上的译是投影，各份真相之间的译才是路由**"；若仍要保留"没有 c 就只能是两两"的强度，**必须补上 §3.1 理由 1 已经用过的那类限定**（v0.5 L139 逐字：「**限定**：这条**只对"没有中间标准"的裸点对点成立**」）——即写成"**在没有中间标准的裸点对点形态下**，没有 c 就只能两两路由"。

**理由三（同一句式在本序已被降级一次）**：v0.5 §五 L319 逐字承认 v0.3 那句"只有当……才可能……"是"**一句全称必要条件句**"，并因 §4.3 声明"不主张充分、也不主张必要"而把它降级。§3.0-c 的后半是**同族句式的重新引入**（"没有 c，就**只能**……"），而 §4.3 的"三件互不代替、不主张必要"（v0.5 L224-225、L233-234）**仍然有效**。⇒ 同一份文件里，§4.3 说"不主张必要性"，§3.0 说"没有 c 就只能……"，**两者需要一个显式的关系说明**（本席的判断：§3.0 这句是"a／b 的**分界**"，而 §4.3 讲的是"三件**方案要件**"——两个论域不同；但**这个不同必须写出来**，现在没有）。

**理由四（判据化之后会产生工程后果）**：一旦"没有 c ⇒ 只能两两路由"被当成判据，它就会推出"**凡不接入 c 的，都是要破坏的对象**"——而这恰好否掉了 §3.2 承认的"标准 + 适配器"这条真实路线，也否掉了 §7.0 前置契约第 2 条承诺的"**最小路径是只读接入**"（L383：先把状态导成事件让别人读，**写路径仍归你**）中"未接入期"的合法性。**这是我的推断**：这一句若按字面执行，会与 §7.0 与 §3.2 同时打架。

### 4.4 一句话回答

**没有正面论证过；它是"需要论证"的，不是"显然成立"的。** 它现在的强度（"**只能**"）**超过**了它手里的证据：既有原文只给了"有 c ⇒ 单向"（定稿 L201）与"a 坏 ⇒ 要 c"（BOOK L84），而"¬c ⇒ a"这半边**既没有出处，也被本序 §3.2 的"标准 + 适配器"路线反证**。**最小改法**：按 §3.1 理由 1 的先例加限定（"在没有中间标准的裸点对点形态下"），或把该格从"因果后果"降为"**定义性分界**"。
