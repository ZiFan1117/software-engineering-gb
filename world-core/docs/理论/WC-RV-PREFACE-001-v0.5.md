## 七、本记录**不能**当什么用

1. **不能当"独立评审"的证据**：两席由同一个执行者派出、核对、归档，签字栏全空；**独立性来自分了席，不来自分了人**。
2. **不能当"专家已复核处置"**：两席回件中**无一份读到过正文 v1.0**；且**两席互不可见，不构成互相印证**。
3. **"采纳"只表示"已落笔"**，不表示"已成立"：正文"它今天做不到什么"一节列出的缺口**不因本轮落笔而变绿**。
4. **行号以"按换行切分"为准**；Windows 上的 pwsh `Get-Content` 会按 ANSI 解码、行数偏小，以行号作证据者禁用之。
5. **本轮的实测缺位**：两席都只做文本与文献核对，**没有跑任何程序**；正文里所有涉及实现的断言，其证据仍是第三轮那份 VM 实测记录（记录件 §7.1）。
