## §2 接口契约要点（逐项非空）
| 项 | 内容 |
|---|---|
| 提供者 | `M07` |
| 输入 | 按 `IF-004` 的输入面（参数／信封字段）；**不接受未在契约中列明的隐式输入** |
| 输出 | 按 `IF-004` 的输出面（返回值／投影文本／错误码）；**输出为纯文本或结构化值，不含二进制序列化** |
| 异常与错误码 | 失败必 **fail loud**：返回带 `ext.world.` 前缀的错误码或明确拒绝；**禁止静默降级** |
| 不变量 | ① 只读接口**不得写 L1**；② 写入只经唯一写入口；③ 同一输入在同一世界状态下输出**逐字节可复现** |
| 判据（可机械核对） | 见 `WC-IRS-001-v0.1` 中 `IF-004` 的「验收判据」与「应当失败的反例」两列 |
