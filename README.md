## 八、术语表

| 术语 | 一句话解释 |
|---|---|
| **载 / 存 / 传 / 管 / 显** | 世界只干五件事：机器秩序 / 状态持久化 / 消息流动 / 权限与审计 / 双投影。详见总纲 §2 |
| **世界核心** | 自建的那一半：语义本体的存储与持久化 + 总线 + 投影注册。**它不是内核** |
| **载体层** | 采购的那一半（现在 Linux）。唯一可以买的一行，判据是"挡不挡路" |
| **脐带 / 进** | 世界与外部的唯一接口：算力 + 旧世界任务。**进口货物可以，进口法律不行** |
| **Harness（挽具）** | 包住大模型的那层程序：工具、读文件、上下文。opencode / Claude Code / DSH 都是 |
| **Capability（能力）** | 细粒度权限单元。比 root 那种"全能钥匙"细 |
| **Landlock** | 内核沙箱（Linux 5.13+）：进程自我声明"我只碰这些路径"，非特权可用 |
| **cgroup** | 给一组进程限资源：内存、CPU、进程数 |
| **journald** | systemd 的结构化日志：带字段，可精确检索 |
