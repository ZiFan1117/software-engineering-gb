# 02-一日实施计划：照 systemd 的剧本做替换（原 05 · 一日实施计划）

> systemd 给出的不是代码，是**剧本**：声明式配置 + 常驻策略层 + 对内核机制做编程。
> 本篇把这个剧本逐角色替换成 agent 版，并给出一天内能走通的最小闭环。

## 1. 替换表：systemd 的每个概念 → agentd 的对应物

| systemd 当年干的 | agentd 怎么替换 | 说明 |
|---|---|---|
| PID 1 / init | **不替换**。agentd 是 systemd 体系下的一个服务 | 关键认知：不是换掉 systemd，是站在它上面。它继续当物业总管，agentd 只管 agent 这一摊 |
| unit 文件（.service） | `cap.d/*.yaml` 能力声明 | 同样的哲学：声明式、启动时加载、支持 reload |
| systemctl（D-Bus 控制面） | agentctl / `varlink call` | 控制面照抄：varlink 进 varlink 出 |
| socket 激活（.socket unit） | provider 懒启动 | 第一次调某能力才拉起对应 provider unit |
| cgroup 管理（Delegate=） | `systemd-run --scope` 拉起每个 agent | **复用** systemd 的 cgroup 管理，一行不重造 |
| journald | 同一个 journald + 字段约定 | INTENT / CAPABILITY / OUTCOME / SNAPSHOT… |
| LoadCredential= 凭据注入 | 给 agent 发 API key 而不给保险柜 | 现成机制，agentd 只做转发 |
| 沙箱指令（ProtectSystem…） | 同款 + Landlock 规则集 | cap.d 的 risk 字段 → 策略模板 |
| After= / Requires= 依赖图 | **不替换**——任务编排是 harness 的事 | infra 保持无聊：底层不规定协同形态 |
| targets（multi-user.target） | 办公室 profile：开机常驻员工集 | enabled 的 agent 服务 = 常驻岗位 |
| .timer 定时器 | 定时 agent 任务 | 直接用 systemd timer 拉 agentd |
| polkit 授权确认 | `require: confirm` 桌面一键确认 | notify-send + 阻塞等待即可起步 |

替换后的一句话：**systemd 管"服务"，agentd 管"agent"，agentd 本身是 systemd 的客户。**

## 2. 一天能走通什么（诚实版）

完整 agentd 是 2-3k 行、1-2 周。**一天 = 最薄闭环**：一个户口、两个 provider、一次快照回滚、一条审计、一道门禁，端到端跑通。

| 时段 | 干什么 | 验收标准 |
|---|---|---|
| 0-1h | 项目骨架 + `agent.service`（02 篇配置原文直接用） | `systemctl status agent` 有户口 |
| 1-3h | cap.d 解析器（~200 行）+ varlink server 骨架（~300 行） | 加一个 yaml、reload、能力表生效 |
| 3-5h | provider #1：brightness（写 sysfs，几十行） | `varlink call` 拿回 `{"newlevel":60}` |
| 5-6.5h | provider #2：package（包 pacman）+ btrfs 快照/rollback 钩子 | 装包前出现 `.pre` 快照，`rollback <id>` 能回 |
| 6.5-7.5h | provider #3：job（活儿登记簿 + 完工铃） | 长任务全程**零轮询**，铃响一次收工（一次推理） |
| 7.5-8.5h | journald 结构化审计写入 | `journalctl -t agentd OUTCOME=failed` 可查 |
| 8.5-9h | Landlock 自锁 + confirm 确认流 | prompt 注入后碰不到白名单外路径 |
| 9-10h | 端到端：03 篇"调亮度 + 装包"两场景 | demo 录屏一段 |

**前置**：Arch/Fedora 测试机 + btrfs、Go 工具链、接受测试期 root。

**明确不进第一天**：A2A 多 agent、能力互斥队列、eBPF、跨发行版适配、正式安全审计。

## 3. 为什么一天是现实的

- 每块的"难"都已被别人解决：unit 语法是抄的、varlink 协议是现成的、Landlock 有官方示例、btrfs 快照是一条命令。
- 新写代码估算：解析器 200 + 路由 300 + 三个 provider 500 + 快照钩子 100 + 审计 100 + Landlock 绑定 100 ≈ **1300 行 Go**——是一天的极限，但够得着。
- 两个已知风险及备胎：
  1. Landlock 在 Go 里的绑定不顺 → 第一天先用 systemd 沙箱指令顶上，Landlock 第二天补；
  2. 桌面通知确认阻塞实现麻烦 → 第一天用 CLI 确认顶上。
