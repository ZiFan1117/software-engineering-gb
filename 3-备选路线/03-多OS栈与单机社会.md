## 1. 什么叫"OS"（本篇的定义）

OS 不是"一个内核"，是一种角色：**独占一类稀缺资源 + 把它虚拟化成稳定接口 + 接口后强制执行策略。**
按此定义，一台机器可以叠多个差异化的 OS，各有各的资源、接口和进化节奏。

## 2. 三层 OS 栈

| | 物理 OS | 社会 OS | 记忆 OS |
|---|---|---|---|
| 管什么 | **物质**：CPU/内存/盘/网络 | **信任**：身份/能力/成员/档案 | **经验**：记忆的存取忘共享 |
| 对外接口 | syscall（进程/文件/socket） | varlink：注册/授权/验证/吊销 | 存/查/授/忘 + 溯源 |
| 实现 | Linux，一行不改 | agentd + cap.d + journald | state 目录 + 插件化记忆引擎 |
| 进化节奏 | 万年不动 | 无聊稳定（法律不天天改） | 最激进（创新主战场） |
| 对人的窗 | 无需 | 授权面板 + 审计查询 | 记忆查看窗 + 遗忘按钮 |

分开的理由：资源不同 → 变更节奏不同 → 信任级别不同。捏成一个大 OS 的下场：
记忆引擎每次升级，法律跟着重写。**分开 = 各自进化，靠稳定接口咬合。**

```
        人（对话 / 授权面板 / 记忆查看窗）
   ┌────────┼─────────┐
   社会OS    记忆OS
   （信任）   （经验）
   └───┬────┬───┘
        身体（harness/DSH，量产标准件）
        大脑（模型，租的）
        │
   物理 OS（Linux：物质）→ 硬件
```

**"人"在接口外侧组装**：身体对社会OS 拿身份权限，对记忆OS 接回过去，配租来的大脑。
人格站在三个 OS 的交点上，不属于其中任何一个。

## 3. 单机社会的构件清单

| 社会要素 | 工程形态 | 底层机制 |
|---|---|---|
| 公民 | agent：户籍（专用用户+unit）+ 私人记忆目录 | systemd / agentd |
| 法律 | cap.d 能力法 + 高危确认 | agentd + Landlock |
| 档案馆 | 不可删改的审计（信誉记录） | journald |
| 经济 | 算力/内存配给（先简单配额，不做市场） | cgroup |
| 集会通讯 | agent 间标准通话 | A2A / varlink / MCP |
| 团体 | 组：共享记忆目录 + 成员名单 + 专属频道 | Unix 组模型 + A2A 频道 |
| 记忆分层 | 私有 / 团体 / 广场 三层 | 文件权限 + 发布订阅 |

**团体 = Unix 组模型（1979 年的机制原样支持 2026 年的社会结构）：**
成员资格 = 一条授权；角色 = 组内权限。
同一 agent 在甲团体可读写工作区（员工），在乙团体只读社交记忆（朋友），
在丙团体是跨机节点（联邦成员）。

## 4. 记忆三层 + 插件化

```
私有记忆   我的 state 目录，Landlock 锁死，只有我能写    ← "我"的延续
团体记忆   组目录，按角色读写，带溯源（谁写的哪条）        ← 共有的，不是公有的
公共广场   发布订阅流（journald/A2A）                    ← 公告与事件
```

**记忆引擎是插件**（身体器官，可换）；**记忆的内容与权限是人格**（归户籍档案，跟人走）。
大脑是租的，"我"是自己的——人格可迁移：换 harness、换模型、换记忆引擎，"我"不散。

## 5. 第四个 OS：试验场（实验舱）

> 社会需要一个合法"搞坏世界"的场所。试验场不是第五层常驻栈，
> 而是物理 OS 的**临时世界模式**：从当前世界毫秒级克隆出一个一次性世界，
> 随便报废，退出三选一。单机多世界（Qubes 分域 / ChromeOS 可弃根 / Firecracker 的合流）。

形态（机制今天全有）：

- 克隆世界：btrfs 快照/子卷，零拷贝毫秒级；
- 进舱：Firecracker microVM（百毫秒启动、硬件隔离）或 systemd-nspawn（秒级）；
- 记账：overlay 层，舱内一切改动只落 overlay，主世界物理碰不到；
- 一次性：销毁 = 删 overlay。

退出三协议（社会 OS 的法定通道）：

1. **丢弃**：删世界，无事发生；
2. **带回**：diff 提取改动清单 → 走 cap.d 法定通道（高危照常确认）→ 应用进社会OS；
3. **存档**：整个实验世界快照进档案馆，供追查。

法律特性——**舱内放权，回归守法**：舱内 root 随便拿（爆炸半径只有舱本身），
cap.d 新增三能力 `lab.spawn` / `lab.commit`（risk=high，需确认）/ `lab.discard`。
社会OS 里所有"不敢让你干"的事都变成"去舱里干"；03 篇的长尾 shell 兜底升级为：
长尾命令跑在一次性世界里，不碰生产世界。

记忆回写：**世界可以报废，经验必须带回**——实验结论由记忆OS 写回私有记忆。

**通道（边界与海关）**：各 OS 之间靠稳定接口互通——社会OS 的 varlink、记忆OS 的存取接口、
实验OS 的 spawn/commit。公民的日常动线：醒来先过通道取回记忆（社会→记忆）、
进舱干活（社会→实验）、成果检疫回社会（实验→社会，走 cap.d）、跨机（社会↔社会，A2A）。
通道上全是海关：**每次跨界在档案馆留一条记录；公民过境只带身份和权限，不带世界。**

## 6. 两条铁律

1. **启动上并列，约束上分层**：内核→systemd→agentd→agent 单向硬约束（锁的体系不能有互否，
   否则死锁）；agent 层对上只有软反馈（观测、诊断、建议走确认与审计）。
2. **infra 不预设协同形态**：群聊制/层级制/联邦制全是上层协议。infra 只强制三条：
   成员=授权、边界=权限、历史=审计。形态随便演化，agentd 一行不动。

## 7. 路线

| 阶段 | 内容 | 验收 |
|---|---|---|
| 一天 PoC（05 篇） | 户籍+法律+审计，单公民落户 | systemctl status / journalctl 可查 / 快照回滚可用 |
| 第二周：团体 | Unix 组挂 agent，团体记忆目录 + A2A 频道 | 三人群聊式 + 两层层级式并存于同一台机，证明 infra 不挑拓扑 |
| 第三周：试验场 | lab.spawn/commit/discard + Firecracker 或 nspawn | 舱内搞坏一切，社会OS 零损，改动清单可带回，经验回写 |
| 联邦 | 第二台机器，同一 agent 两处户籍，A2A 跨机 | 跨机协作的第一个真 demos |

## 8. 诚实难点

1. **共享记忆的写污染**：幻觉成员污染团体记忆 → 写操作带溯源与签名，档案馆可追责；
2. **资源经济**：先做明文配额，别上市场机制；
3. **能力转授**：Landlock 是自我声明，agent 间委托逻辑做在 agentd（策略面职责）；
4. **数字生命同一性**：依赖 state 与审计的持久性——备份与快照策略要从第一天就是设计项，不是运维项。
