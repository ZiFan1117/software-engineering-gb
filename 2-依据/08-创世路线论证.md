## 一、不兼容改变了什么

1. **砍掉所有旧世界器官**：DOM 转译层、MCP 方言、过渡桥——全是"接口旧世界"的部件，
   自足世界不需要。transferor 从架构内组件降格为**可选外设**（进口海关，想读旧网页才接）；
2. **浏览器投影重新定义**：不是"渲染存量 web 的浏览器"，是**语义世界的文档查看与
   导航器**——看自己世界的内容空间。存量死亡陷阱（AOM 尸体）全部消失；
3. **方法论换血**：分层施工 → **垂直切片 + 自举**。自足世界无法按层造（没有投影看不见
   内核，没有内核投影无物可画），第一刀必须切穿全部，然后在世界内开发世界。

参考系对照：移民路线看 Ladybird（一生追兼容）；创世路线看 **Smalltalk**（image 自足、
世界内开发）、**Oberon**（OS 即文档环境、朴素投影）、**Genera**（Symbolics 完整自足世界）。

## 二、创世四阶段

### 阶段 A：定义世界的物理（设计）

语义本体最小集：**实体/状态/动作/事件/引用 + 身份 + 能力权限模型**。
这是世界的物理定律，一切按它构成。产出：内核 spec v0。

### 阶段 B：垂直切片（世界雏形，一刀切穿）

- 微内核：语义树的存储与持久化（Smalltalk 式 image 文件）；
- 总线：唯一 IPC，消息即语义事件；
- 渲染投影 v0：朴素到文本模式皆可（Oberon 式）；
- 两个内置应用：文件浏览 + 一个可交互应用（证明世界能活）；
- agentd 内建：能力表/审计/完工铃；
- 一个 agent 接入（LLM 外部调用=算力外购，不算兼容）。

**验收唯一标准：boot 进这个世界，人用投影操作、agent 过门禁操作，同一份状态、
同一块屏幕。**

### 阶段 C：自举循环（生长方式）

- 从此**在世界内开发世界**：编辑器/终端/调试器迁入成为世界内应用；
- 内容由 agent 批量生成——agent 是原住民生产力，解决"新世界空无一物"的冷启动。

### 阶段 D：向外表（可选，最后）

- 世界↔世界网络协议（语义世界互连，非 WWW）；
- 旧 web 进口海关（transferor 以外设身份复出）。

## 三、地基决定（内核的定义、职责与换轨条件）

**"内核"的准确定义**：操作系统里唯一被硬件直接信任、唯一能执行特权指令、唯一能裁决
一切资源与访问的那层软件——硬件之上、一切软件之下的第一层仲裁者。能干的只有六件：
分配时间（调度）、分配空间（虚拟内存）、翻译持久化（文件系统）、翻译设备（驱动）、
传递消息（IPC）、强制隔离与权限。**内核不提供应用价值，只提供秩序**——时间的、空间的、
资源的、权限的秩序；语义住在语义层，与内核两轴正交（要求内核语义级=要求地基懂建筑学）。

**内核干的事**：把物理机器翻译成抽象机器并仲裁使用权——造并发幻觉（调度）、
造独占内存幻觉（虚拟内存）、把磁盘字节变文件（VFS）、把网卡变套接字（网络栈）、
裁决资源与隔离（权限/cgroup/namespace/seccomp/Landlock）。工作在"字节与周期"层。

**内核不需要语义级，这是分层的正确形态**：语义关于意义，内核关于资源，两层正交——
要求内核语义化等于要求地基懂建筑学。判据是"原料够不够语义世界的牙齿"：
Linux 四样原料全给（隔离/配额/持久化/承载——即 agentd 的强制力、agent 资源治理、
世界 image 的存储、总线的传输）。

**默认值**：先站 Linux 内核（如 Omarchy）：世界的身份在语义层不在内核层，硬件抽象
是可换插座；不对 Linux 之上的软件生态做任何兼容承诺。**为什么不是一出生就站 seL4**：
seL4 是微内核，只给最核心一小块（IPC/调度/内存/能力控制），驱动、文件系统、网络栈
全得自己长——先站 Linux 把世界生出来，长大再换轨，四行合同保证平移不拆楼。

**换内核的三个真实条件**（从来不为语义，只为这三样）：
1. 能力强制下沉硬件级（内核原生只认能力句柄）——候选：**Zircon**（Fuchsia：
   一切皆对象、访问皆句柄，哲学上最接近 cap.d 世界观）、**seL4**（形式化验证）、
   Redox（Rust）；
2. 绝对自足去倾向（裸金属/最小微内核，扔掉整层不可信用户态）；
3. 硬实时/形式化安全认证。

**Zircon 核查注记（2026-09-25）**：GitHub 镜像已探不到、谷歌源站本网不可达——
当前活跃度无法亲验；可靠信息止于 2023（Nest Hub 在跑、项目收缩裁员）。
战略风险：**命运捏在谷歌手里**。故定位修正：Zircon 是"观念样板"（证明票据内核
可造可跑），**换轨执行首选 seL4**（数学证明正确 + 独立基金会，不押巨头战略耐心）。
Zircon 的"票可剪权利/票可传递可收回"原生语，恰是 00.2/00.3 授权讨论的内核级对应物。

**换轨成本与合同**：自举工具链全部重来，故定为"世界长大后的插座更换"而非出生决定。
我们对下层的合同只有四行（隔离/配额/持久化/承载）——换插座时合同不变，
语义层整体平移。

## 五、待批判项

1. **冷启动的深度**：自举要求世界先能承载开发工具——最小开发环境（编辑+运行+调试）
   的下限比"两个内置应用"高，阶段 B 的范围可能被低估；
2. **算力外购的依赖**：agent 靠外部 LLM——世界最核心的生产力其实在境外，
   "自足"有豁口（纯度问题：算力依赖 vs 软件兼容，界线是否站得住）；
3. **单机世界的历史宿命**：Smalltalk/Genera 皆败于与开放生态的竞争——
   不兼容路线的历史胜率极低，需明确"这次为何不同"（答案候选：agent 是原住民、
   无需说服人类迁移——世界为 agent 而建，人只需要投影）。
