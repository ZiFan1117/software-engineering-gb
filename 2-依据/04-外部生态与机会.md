## 1. 位置图：四层玩家，各就各位

| 玩家 | 所在层 | 做了什么 | 没做什么 |
|---|---|---|---|
| **Omarchy**（42.6k★，$21.7M 资金） | 桌面集成层 | 预接线 10 个 agent、崩溃诊断胶水、skill 分发、QML 插件壳、omakase 默认值 | 没动 systemd/内核/权限模型。agent 仍是"贵宾用户" |
| **harness 们**：opencode、Claude Code、DSH（233k★/一个月） | 模型外壳层 | 模型→工具的插件化（DSH："Everything is a Plugin"） | 视野停在**进程边界**：不管 OS 怎么管理它、限制它、审计它 |
| **并行造轮子们**：elizaOS（19k★）、openfang（18k★）、AIOS（6k★）、rivet agentos（4.6k★） | "agent OS"概念层 | 自造编排框架、自己的"内核"抽象、云沙箱 | **绕开 Linux 既有地基**，在用户态重复发明 cgroup/varlink/沙箱 |
| **Linux 本体**：systemd、内核 | 机制层 | varlink、cgroup、Landlock、eBPF、coredump 事件、journald | **没人从 agent 视角把这些组装过** |
| **NixOS / btrfs** | 回滚层 | generations / 快照，全局可回滚 | 没有 agent 概念，不会"动作前自动拍快照" |

## 2. 裸机实验已经出现（方向被验证，工程没人啃）

- **akasha-os**：seL4 微内核 + capability-based security + semantic IPC + 一等 GPU —— 3 star
- **Bare-Metal-Agent-Native-OS**：UEFI 直启、本地 transformer、能力安全、不要 Linux/Windows —— 0 star
- **earendel**：V8 上的 agent-native 微内核 —— 2 star

结论：**"agent 需要能力安全 + 结构化 IPC"这个方向已有人押注**，
但"抛弃 Linux 重来"路线拿不到生态；赢面在"给 Linux 装适配器"。

## 3. 缺口 = 机会

> 一个把机制层四件套（**cgroup / varlink / Landlock / 快照**）正式接给 agent 的
> 守护进程 + 发行版。目前不存在。

参照物：DSH 证明了"harness 内插件化"一个月 233k star；
"OS 内插件化"（agent 作为系统能力组件）连 1% 都没人做。
Omarchy 的 $21.7M 证明了市场愿意为"agent × Linux"付钱——而它只做到了胶水层。

## 4. 如果想动手：最小 PoC 路线（约 2-3k 行 Go/Rust）

| 步骤 | 内容 | 验收标准 |
|---|---|---|
| 1 | `agentd`：systemd unit + cap.d 解析 + varlink 转发 + journald 写入 | `systemctl status agent` 可见；动作在 journal 里可查 |
| 2 | 三个 provider：brightness（写 sysfs）、network（包 NetworkManager）、package（包 pacman） | 三个能力全部结构化调用、结构化返回 |
| 3 | 快照钩子：risk=high 前自动 `btrfs subvolume snapshot` | `agentd rollback <id>` 可用 |
| 4 | Landlock 默认策略 + 专用用户 + NoNewPrivileges | 攻击测试：prompt 注入后 agent 碰不到白名单外路径 |
| 5 | 跑通"修 WiFi"全场景（见 03 篇） | 这就是 demo 视频 |

## 5. 一句话总结

> Linux 用 30 年把自己造成了人类最好的"可插拔机器"——
> agent 是它等了 30 年的那个使用者，但今天两者还隔着一条命令行鸿沟。
> 把桥正式建起来的人，做的不是又一个发行版，是 OS 的下一次变形。
