## 一、"应该"的地基：不可逆性论证（替换镜子论留下的空位）

镜子论降级后，"该保留监督"失去了论据。本节给出不依赖任何隐喻的论证：

1. 有些效应不可逆（转账、发出消息、删除、第三人受影响）——事实；
2. Agent 错误率非零且不可归责（00.1 第六节已证）——事实；
3. 不可逆 × 不可归责 = 错误一旦发生，**无任何事后机制能恢复或追索**——推论；
4. 故对不可逆效应，**事前/事中介入是唯一存在的纠错点**——推论；
5. 故保留介入能力（监督）对不可逆效应是必要的——**纠错点的逻辑必然，非价值偏好**。

**最强反驳（快乐箱）**：事事满意何必亲眼看。它对**可逆效应**成立（错字能改，不必盯），
故监督不必全覆盖；对**不可逆效应**失效——会被不可逆伤害的"快乐箱"不是快乐箱，是温水锅。

**产出**：监督的"应该"只覆盖不可逆效应；对可逆效应，放手合理。顺手解决了摩擦原则与
效率的冲突：**摩擦按不可逆性定价**——这比旧"七原则"里的摩擦原则多了一个可操作判据。

## 二、制度空白：四条路径的代价与时序组合

| 路径 | 代价 | 判定 |
|---|---|---|
| 新责任类别（类航空器适航） | 立法以十年计、跨国难协调、定型前空档裸奔 | 终局方案，远水 |
| 厂商全责 | 小厂商出清、垄断加剧、跨国执行难 | 过渡可用，副作用大 |
| 强制保险 | 道德风险；且**只赔钱不纠错**——按第一节的结论，钱换不回不可逆 | 对可逆损失有效，对不可逆无效 |
| 架构化责任（agentd 路线） | 唯一工作在事前/事中（守在纠错点上）；但技术结构承载规范性的前提待论证（日志证明"谁做的"，证明不了"该不该"；授权效力依赖处分权——见第五节） | **必要不充分** |

**组合判断**：近期 4+2（架构化 + 厂商责任），中期加 3（保险覆盖可逆损失），
远期 1（类别定型）。没有单一答案。

## 四、单机视角：不是错误，是未标注的域

"动物园研究候鸟"的指控部分成立：厂商中介、多主体、网络效应确在单机之外。
但单机视角回答的问题本身合法（"人与身边这台机器的关系"是正当的分析单元）。
真正的错误是**定义的适用范围被默认放大**——说"Agent 是什么"时被读成"一切 Agent"。
修正：单机定义的域 = "作为使用者身边执行单元的 Agent"；厂商中介与多 agent 社会
属于另一分析层（06 篇已画层次），需自己的定义工作。**标注域，而非推翻。**

## 五、两个地基词的审查："能力"与"行动"

### 5.1 能力：声明即授权 → 声明即请求

"声明即授权"依赖未论证的前提：人对计算机操作有处分权。审查发现三处受限：

1. 机器上有**别人的利益**（许可证、数字版权、云端数据的实际控制者）——处分权是
   **受限产权**（类比租房：能用，墙不能拆）；
2. **授权不能超出授权者的权限**——账号在平台条款下只是使用许可，转授的也只能是
   使用许可；agent 的自动化行为可能恰好违反该许可（反自动化条款）——授权链断裂；
3. **对第三人无效**——授权 agent 侵犯第三人，授权自始无效。

**修正**：cap.d 的本质是**请求的登记与过滤**，其效力上限是使用者的受限产权；
越过产权边界的声明（碰平台权利、碰第三人权利）自始无效。
（理论修正，不改代码；agentd 的白名单机制恰好是实现"请求过滤"的正确形状。）

### 5.2 行动：agent 的 exec 是"被组织成行动形状的事件"

哲学区分：行动 = 有意向的事件（可归责于行动者）；事件 = 单纯发生（只能追因）。
agent 的 exec：结构上有意向的形状（有目标指向），来源上无意向的地位（目标是植入的，
不是它的）。对应物是**工具的"倾向"**（刀"想要"切割是拟人说法）。

**归责推论**：归责不落在 agent（事件无归责），落在**把事件组织成行动形状的人**——
设计意图的植入者（厂商）与任务的发起者（使用者），按各自贡献分摊。
与第二节的组合判断（架构化 + 厂商责任）相互咬合：架构记录"发生了什么"（证据），
归责分摊决定"算在谁头上"（规范），两者缺一不可。

## 六、本篇产出汇总与待批判项

**产出**：不可逆性判据（监督与摩擦的定价标准）；制度时序组合（4+2 → +3 → 1）；
写作方法决定；定义的域标注；声明即请求；归责按组织贡献分摊。

**待批判**（本篇自己的弱点，先自首）：
① 不可逆性论证把"必要性"证明了，但没证"充分性"（监督必要≠监督有效）；
② 归责分摊的"贡献度"如何度量，未给出可操作标准；
③ 时序组合的判断含时间预测（"远期"），有猜测成分。
