## 一、三个名字（现行定义）

| 名字 | **现行定义** | 它**不是**什么 |
|---|---|---|
| **Computer** | **被持续争夺的执行场所**——它的每项属性（谁能看、谁能改、谁被执行）都是争夺的暂时结果，不是本性 | 不是中立舞台（更新策略、遥测、云端裁决 = 场所在有倾向地行动）；不是行动者（有行为，无自身意志） |
| **人** | **在"原料 ↔ 客户 ↔ 监督者"循环中被轮流指派的位置**，且**监督者角色结构性衰减** | 不是单数（至少四个角色：使用者/被影响者/供给者/规制者，本理论取使用者）；不是并列的"角色集"（角色之间是循环，定义里必须写进时间） |
| **Agent** | **责任结构未定型的拟受托造物**（本体/边界/因果三层）；**规范层上它是三股定型力量争夺的战场**，"未定型"是**僵局**而非本性 | 不是受托人；不是合格产品；不是镜子；不是"人类过去的集合" |

### 1.1 Agent 的四层定论

| 层 | 定论 |
|---|---|
| **本体** | 软件制品：**可替换流水线**（模型 + 工具 + 状态），每次会话实例化，零件分属不同所有者 |
| **边界** | 无物质边界，只有功能边界——"它" = 此刻正替这次任务运转的那条流水线；**可替换是本质属性，不是事故** |
| **因果** | 有偏人类记录的**平滑压缩** + 当下设计决策（厂商策略、系统提示）+ 当下输入。**Agent ≠ 模型** |
| **规范** | **定型战场**：产品化 / 受责化 / 受托化 三股力量正在争夺它的归类 |

### 1.2 三条不可省的澄清

1. **是"三重约束"不是"三重委托"**：约束是事实（任务 × 策略 × 法律确实约束着它），
   委托是制度（不存在）。**描述事实的词与宣告制度的词不得混用。**
2. **不是受托人，但理由要说准**：委托的五个必要条件（义务资格 / 标的确定 / 以委托人利益为目标 /
   可问责 / 承诺成立）**逐条不通过**。但"概念性不可能"是修辞升级——现行制度下不可能，
   **建构路径开放**；真正剩下的概念障碍只有一条：**塑形 ≠ 守诺**（无立场则无所谓违背）。
3. **镜子论已降级**：它学的是"人怎么说"，不必然是"世界怎么运行"。镜子论是**启发式隐喻**，
   不再是证明链的一环（其认识论推论保留）。

### 1.3 定义即参战

说 Agent"未定型"，本身就是在对抗"只是工具"与"是伙伴"两种定型。
**本理论工作也是一股定型力量**——这是必须自认的立场，不是中立描述。

## 二、三者关系：一个自我强化的循环系统

```
人循环的每一圈 ──给 Agent 的战场输送弹药（数据加固模型、信任加固受托化）
定型结果      ──改变 Computer 的争夺格局（谁的定型赢，机器按谁的主权配置）
```

三角不是三个东西的关系，**是一个循环系统**。三种关系状态：

| 关系 | 状态 | 本质 |
|---|---|---|
| 人 ↔ Computer | **占有**（稳定） | 工具契约照旧；但场所有倾向，权力分析时必须计入 |
| 人 ↔ Agent | **未定型** | 让渡执行、监督能力衰减；需要"目标 + 授权 + 证据" |
| Agent ↔ Computer | **借道**（须被治理） | 须证明行动在授权范围内 → 门禁 / 审计 / 回滚 / 响铃 |

**僵局何时破裂（论定）**：三股力量互相抵消，谁都赢不了——**僵局不会自己破**。
它只由**外部冲击**打破，而冲击只可能来自三处：

| 冲击位 | 形式 | 破局方向 |
|---|---|---|
| **法律** | 新责任类别落地（类适航） | 定型为"受责造物" |
| **基础设施** | 可问责性变便宜（门禁 / 审计成为默认件） | 产品化的成本优势消失 → 被迫受责 |
| **规模** | agent 中介的交易成为主流 | "不构成建议"的免责在大规模下无法维持 |

**三处里只有基础设施是建造者自己能动的**（法律以十年计、规模由市场决定）。
所以本项目的准确位置不是"顺便参与定型"，而是：
**在三个破局点里，挑那个不需要等立法的。**（完整论证见 §10.1）

## 三、核心动力学：监督必要、但不充分、且在衰减

这是全套理论最硬的一条，也是它真正的核心（不是弱点）：

1. **必要**：对不可逆效应，事前/事中介入是**唯一存在的纠错点**（证明见 §四）；
2. **不充分**：监督能力随依赖增长而**衰减**——**依赖与监督互斥**；
3. **反噬**：监督行为本身改变责任结构——**批准即背书**，人批准过的事故反而锁死追责。

**直接推出的工程要求**：协作机制必须**补偿**衰减——把监督从"注意力问题"变成"架构问题"
（预定检查点、事件推送、完工铃、结构化审计）。

## 四、规范地基：不可逆性 + 摩擦定价 + 预案分级

**论证（五步）**：有些效应不可逆 → Agent 错误率非零且不可归责 → 不可逆 × 不可归责 =
事后无任何机制能恢复或追索 → 故对不可逆效应，事前/事中介入是唯一纠错点 →
**监督对不可逆效应是必要的**（纠错点的逻辑必然，非价值偏好）。

**最强反驳（成立）**：不可逆的边界**需要判断**，而判断正是已让渡的能力——
"人必须先监督才能知道哪里需要监督"（循环）。

**幸存者（现行立场）**：

- **不可逆性不由当次判断，由预案分级制度化**（如手术分级：术前按类别定级，非术中现场判断）
  → 循环由此打破。工程对应物：能力声明里的 `risk` 字段；
- **摩擦按不可逆性定价**：可逆处放手，不可逆处加摩擦；
- **判据会移动**（今天可逆的明天不可逆）→ 因此**可逆性必须能被本体记录与重判**
  （工程含义见 [../00-总纲.md](../00-总纲.md) §2.2 与 §6）；
- **审计必须区分"人批准"与"人被信息胁迫后批准"**（记录批准的语境）。

## 五、能力与归责：声明即请求 / 产权三档 / 场景归责三桶

### 5.1 能力 = 声明即请求（不是授权）

门禁的本质是**请求的登记与过滤**，不是授权。它的效力上限是**使用者的受限产权**：

| 档 | 区域 | 效力来源 |
|---|---|---|
| 真业主区 | 平台、云端数据 | **许可边界**（能用，墙不能拆） |
| 无业主区 | 开源、协议、公共数据 | **惯例与互惠**（不是"权限有限"，是**谁都够不着**） |
| 全产权区 | 本地文件 | 完整 |

**越过产权边界的声明，自始无效**（碰平台权利、碰第三人权利）。

### 5.2 行动 = 被组织成行动形状的事件

- **行动** = 有意向的事件（可归责于行动者）；**事件** = 单纯发生（只能追因）；
- Agent 的 exec：**结构上有意向的形状**（有目标指向），**来源上无意向的地位**（目标是植入的）；
- 对应物是工具的"倾向"（刀"想要"切割，是拟人说法）。

### 5.3 归责 = 落在把事件组织成行动形状的人

不落在 Agent（事件无归责），落在**设计意图的植入者（厂商）**与**任务的发起者（使用者）**。

**场景归责三桶**（不切比例，一桶一个机制）：

| 桶 | 情形 | 机制 |
|---|---|---|
| 设计缺陷致错 | 厂商 | 厂商责任 |
| 任务指令致错 | 使用者 | 使用者自担 |
| 分布内随机错 | 谁都没错 | 保险池 |

## 六、制度空白：四条路径与填充时序

| 路径 | 代价 | 判定 |
|---|---|---|
| 新责任类别（类适航） | 立法以十年计、跨国难协调 | 终局方案，远水 |
| 厂商全责 | 小厂商出清、垄断加剧 | 过渡可用，副作用大 |
| 强制保险 | 道德风险；**只赔钱不纠错** | 对可逆有效，对不可逆无效 |
| **架构化责任**（把可问责性造进系统） | 唯一工作在事前/事中；效力上限见下方论定 | **必要不充分** |

**技术结构能承载什么（论定）**：把这个问题一次论清——**技术结构能承载"程序"，不能承载"标准"**。

- **能**：证明"谁在何时做了什么、有没有越界"——这就是**可问责性**；
- **不能**：证明"这么做对不对"——那是**正当性**，只能由法律与制度给出。

所以架构化责任的准确效力是：**把"不可追责"变成"可追责"，不把"不该做"变成"不做"**。
它的上限由此定点：**它能消灭"查无此人"，消灭不了"合法但有害"。**

**时序组合**：近期 **4 + 2**（架构化 + 厂商责任）→ 中期 **+3**（保险覆盖可逆损失）→ 远期 **1**（类别定型）。

**日落条款**：架构化责任的审计格式必须是**中立 / 用户主权**设计——否则过渡方案会固化为
厂商的免责工具（"时序即权力"）。

## 七、协作的应该形态与承载

### 7.1 三对闭环

| 对 | 应该形态 | 高效 = |
|---|---|---|
| 人 ↔ Agent | **契约协作**：目标（一次一个可陈述的"把 X 做到 Y"）+ 授权（范围 + 不可逆预案级别）+ 证据（结果 + 留痕 + 哪步是推测） | 不重复谈判 |
| Agent ↔ Computer | **门禁协作**：**声明即请求**，场所按产权三档过滤 | 请求可预算（执行前就有确定的通过/拒绝/需确认） |
| 人 ↔ Computer | **投影协作**：界面成为三方协作状态的投影（进行中任务 / 待确认请求 / 高危预案） | 一个表面看全 |

### 7.2 四条高效判据（可检验）

1. **谈判一次**；2. **监督零盯守**；3. **纠错在最近点**（执行前过滤 > 执行后审计 > 事后发现）；
4. **争夺可见**（每个动作能回答"谁授的权、谁的场所、谁受益"）。

**四条判据的测量（协议）**——判据不是修辞，逐条可测：

| 判据 | 度量什么 | 达标线 |
|---|---|---|
| **谈判一次** | 同一目标的**重复谈判轮次** | 0 轮 = 达标；1–2 轮 = 可接受；≥3 轮 = 未达标 |
| **监督零盯守** | 人不在场期间完成的任务占比 × **事后可答率** | 事后可答率 = 能答出"做了什么、哪些在等我批"的比例，须 100% |
| **纠错在最近点** | 错误**发现点**距**执行点**的距离 | 执行前 > 执行后 > 事后（三档递减，取分布中位数） |
| **争夺可见** | 任一动作能否回答四问 | 谁授权 / 谁的场所 / 谁受益 / 谁承担——**四问全答得上**才达标 |

### 7.3 承载：底座 + N 投影（"中间点"模型已证伪）

**证伪**：找一个"三方都能懂的中间语言"不成立——三方的"硬件"不可通约，
任何单一格式必然降级到最低公共水平。**中间点是求交集，交集必然小于全集。**

**现行结构**：

```
真相层：语义总线（一份数据：状态 / 动作 / 事件）
   ├── 投影 1：自然语言（人对话时用）
   ├── 投影 2：图形界面（人看状态时用）
   ├── 投影 3…N：听觉等（留位；新增端口必须同源）
   ├── 直连：Agent 原生读写（它本来就说结构化）
   └── 直连：Computer 原生执行（它本来就要指令）
```

三个区别：**位置 vs 底座**（谈判桌 vs 同一份档案）、**妥协 vs 不妥协**（交集 vs 各取最优版本）、
**平等 vs 不对称**（三方对等 vs 机器直连、唯人配随行翻译）。

**损耗**：从"三方两两互译"降为"底座 → 人的投影"——**翻译只发生在一个方向上，且从同一真相出发**。

## 十、四处理论弱点的论定

**这一节不给"未定"**——每条都是**结论 + 失效条件**。失效条件不是回避，是边界：
它说清"这条在什么情况下不成立"，从而让成立的那部分可用。

### 10.1 僵局何时破裂（§二留下的那条）

三股力量互相抵消，**僵局不会自己破**，只由外部冲击打破，而冲击只有三处：

| 冲击位 | 形式 | 破局方向 |
|---|---|---|
| **法律** | 新责任类别落地（类适航） | 定型为"受责造物" |
| **基础设施** | 可问责性变便宜（门禁 / 审计成为默认件） | 产品化的成本优势消失 → 被迫受责 |
| **规模** | agent 中介的交易成为主流 | "不构成建议"的免责在大规模下无法维持 |

**结论**：三处里**只有基础设施是建造者自己能动的**（法律以十年计、规模由市场决定）。
本项目的准确位置因此不是"顺便参与定型"，而是：**在三个破局点里挑那个不需要等立法的**。

**失效条件**：若法律先行（新责任类别在基础设施成熟前落地），本项目降级为"配套件"，
不再是破局点——但结论方向不变，只是它不再是唯一的那一处。

### 10.2 "定义即参战"的自我豁免

风险成立：一个宣称"定义即参战"的理论**无法自证**它不是又一股伪装中立的定型力量
——自证在结构上不可能。

**结论（交出判据，接受判决）**：唯一不自欺的做法是**预先立判据**——
**判据 = 它最终把机制交到谁手里。**

| 产出 | 判定 |
|---|---|
| 让**厂商**更容易定型的基础设施（集中审计 / 厂商持有授权 / 状态不可导出） | **伪装中立的定型力量** |
| 让**使用者**更容易定型的（本地主权 / 可导出 / 建造者无特权） | **站在使用者一边** |

**失效条件（同时是本项目的死亡判据）**：一旦审计集中到厂商、或世界状态不可导出，
这条判据**立刻判它输**——不需要等历史评价。

### 10.3 共同致错的归责（"边界案例"是假问题）

"设计缺陷与任务指令共同致错"看似需要比例切分，其实**不需要**。两步判定即可化归单桶：

1. 触发错误的输入，是否落在**合理可预见的使用范围**内？
   **是 → 厂商**（设计缺陷）；
2. **否 →** 使用者是否被**充分告知**了边界？
   **未告知 → 厂商**（警示缺陷）；**已告知 → 使用者**。

**结论**：共同致错**总是落在单桶里**，不需要比例切分。

**失效条件**：当"合理可预见"本身没有先例（新技术首次出事），两步法失去参照——
此时归入**保险池**，由定价吸收，而不是由判决硬切。

### 10.4 单机理想与云算力：结论域的划分

单机理想的真实假设有三条：跨会话记忆连续、**模型行为在两次调用之间稳定**、状态不被第三方可见。
云模型让第二条不成立——**厂商可以在会话之间改策略**。

**结论（结论域划分）**：**会话内的结论有效；跨会话的结论一律重算。**

| 结论 | 域 | 为什么 |
|---|---|---|
| 纠错点在执行前 / 执行中 | **会话内有效** | 纠错点本身不跨会话 |
| 监督按不可逆性定价 | **会话内有效** | 同上 |
| "它记得上次是怎么做的" | **跨会话失效** | 模型行为可被会话间策略改变 |
| "它明天还是这样" | **跨会话失效** | 同上 |

**失效条件**：若模型行为在会话之间被证明稳定（例如本地模型），偏离归零，
单机结论**全域有效**。

### 10.5 保险对不可逆效应：只作用于事前

原判"只赔钱不纠错 → 对不可逆无效"**过快**。正确形态是分层：

- 对**可逆**损失：保险**直接有效**——赔付即纠错；
- 对**不可逆**损失：保险**事后无效**（钱换不回已发生的事），但**事前有效**——
  保费定价把不可逆风险折进成本，在行为发生**之前**改变行为（车险之于刹车）。

**结论**：保险对不可逆效应**只作用于事前，不作用于事后**。因此它在时序组合里的位置是
**中期（+3）**，既不能被排除，也不能替代事前门禁。

**失效条件**：若保费定价无法反映个体行为差异（风险池被拉平），事前调节功能消失，
保险退化为纯赔付——那时它对不可逆效应确实无效。

### 10.6 唯一不能论定的一项

**三处冲击哪一处先到**——这是**预测**，不是理论缺口：理论给的是"破局只可能来自这三处"，
以及"只有一处是自己能动的"。预测谁先到需要外部数据，与理论是否成立无关。
