## 一、五层判别线（书的骨架：每一层只回答一个问题）

| 层 | 判别线 | 允许出现的词 |
|---|---|---|
| **L1 问题** | 今天缺什么、缺到造成什么后果 | 现象、例子、缺口、后果 |
| **L2 规格（应有）** | 那一层**应当**是什么样 | 定义、名字、构成、边界 |
| **L3 命题** | 为什么这件事不能由参与方自己解决 | 前提、命题、理由、失效条件 |
| **L4 机制** | 它**怎么**落到机器上 | 入口、身份、读法、适配 |
| **L5 兑现** | 已经定下来的规格，今天**做到几分**（红绿可判） | 实测、红／绿、上限 |
| **L6 未定** | 哪些规格**还没定**，要人裁 | 未定义、待人裁、欠账 |

> **判据**：L5 与 L6 的分界＝**能不能判红绿**。能判红绿的进 L5（规格已定、只是没做到）；判不了红绿的进 L6（规格本身没定）。

## 四、十条写作纪律（书的自我约束；规格与流程文档**不受**此约束，但冲突时要说明谁让）

| # | 纪律 |
|---|---|
| 1 | 一章只承担一层（层见 §二；一章里出现两层，拆章） |
| 2 | 一节只讲一个小点，节名不得含并列两事（节名里出现"与／和／及"，先怀疑该拆节） |
| 3 | 高层次不给细节，低层次不重复论证；一章之内只许出现本层允许的词 |
| 4 | 不解释自己：不写"上面说的是…这里说的是…"、不写"本节分三部分" |
| 5 | 凡涉及实现的断言必须可核：要么给可复现的命令，要么改写 |
| 6 | 内部争论、评审意见、版本沿革、待人裁清单一律不进正文（进记录件） |
| 7 | 章名、节名里不许出现读者还没学过的行话——用书里已经讲过的词，或换成白话 |
| 8 | 同一事物允许在两层各出现一次，前提是视角不同：一层讲"应当有"，另一层讲"今天哪几格没有"——只在一层展开，另一层一行指向节号。位置与纪律 10 的冲突已裁：那"一行指向"排在该节末尾直结论之前，不占结论的位置（第六章各节原是按这个位置手工摆的，此处写明即成规矩） |
| 9 | 依据栏必须逐节核实：指向错节、过弱、"拿缺位当规定"、该标待人裁而未标——四类一律先改框架 |
| 10 | 推导可以绕，落笔不许绕：禁止"不是 A，而是 B"这类句式（直接说是什么）；禁止"不得不""并非""与其说…不如说""与其 A 不如 B"；少用排比、少用破折号插入；每节末尾给一句直的结论（≤30 字，读者能直接复述的） |
