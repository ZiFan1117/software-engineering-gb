> 用最低成本暴露框架的结构性错误，此时推翻框架的代价最小。**可裁剪，须留痕。**

## 四、模板的自声明约束（每份模板都写了，但要知道）

每份模板文件头都声明了四件事，**填之前先读它**：

| 声明项 | 作用 |
|---|---|
| **文档编号规则** | 这份文档该怎么编号 |
| **适用阶段** | 什么时候写、什么时候维护 |
| **准出门禁** | 归哪个评审审、通过标准是什么 |
| **依据标准** | 内容要求出自哪份国标 |

模板末尾通常还标明了：
- 哪些内容属**国标原文要求**
- 哪些是本仓库的**工程强化项**
- "实施时请以标准正文为准"

> **这条很重要**：模板**不复制标准正文**（版权原因），
> 所以它是**结构骨架**，具体内容要求须回标准核对。

## 六、怎么用模板（操作步骤）

```
① 按档位与阶段，从 §二 找到该取哪份
② 打开模板，先读文件头的四条自声明
③ 复制到你的项目仓库，按编号规则命名
④ 填写。遇到"依据标准"标注的章节，回标准核对具体内容
⑤ 填完过一次门禁（A 档跑命令，B 档开评审）
⑥ 基线化，打标签
```

**批量取用的建议**：

```powershell
# B 档：把整套模板拷进项目仓库
Copy-Item -Recurse templates\ <你的项目>\docs\templates\

# A 档：只取需要的那几份
# 不需要拷贝，按 §一 的对照表直接从 templates/ 取用
```
