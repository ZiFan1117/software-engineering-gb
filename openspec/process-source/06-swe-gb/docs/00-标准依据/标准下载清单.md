# 标准下载清单

> **用途**：把这份清单直接转给帮忙下载的人。每条都写清了**标准号、全名、年份、优先级**，
> 以及**怎么核对版本对不对**。
>
> **整理日期：2026-09-21**
> **核对入口**：[全国标准信息公共服务平台](https://std.samr.gov.cn/) ·
> [国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/gb/)

---

## ⚠️ 先看三条，避免拿错

| 坑 | 说明 |
|---|---|
| **必须核对年份** | `GB/T 8567` 有 **1988** 和 **2006** 两版，标题只差几个字——1988 叫《计算机软件**产品开发**文件编制指南》，2006 叫《计算机软件文档编制规范》。**要 2006 的** |
| **必须核对年份** | `GB/T 8566` 有 **2007** 和 **2022** 两版。**要 2022 的** |
| **⚠️ 有一份同名陷阱** | **`GB/T 29110-2012` 是道路交通标准**（《道路交通信息服务 公共汽电车线路信息基础数据元》），**与软件完全无关**。如果下载到这份，说明搞错了——我们要的是 **ISO/IEC 29110**，不是 GB/T 29110 |

**核对方法**：拿到文件后，看标准号 + **发布年份** + **中文全名** 三项是否都对得上本文。

## 一、第一优先：六份核心依据（必备）

这六份是流程的**法源**。缺任何一份，对应阶段就没有依据。

### 1. GB/T 8566-2022
- **全名**：系统与软件工程 软件生存周期过程
- **英文名**：Systems and software engineering — Software life cycle processes
- **发布 / 实施**：2022-10-12 / 2023-05-01
- **管什么**：**过程框架**（有哪些过程、怎么衔接）
- **采标**：等同采用 ISO/IEC/IEEE 12207:2017
- **⚠️ 别拿**：GB/T 8566-2007（旧版）

### 2. GB/T 45802-2025
- **全名**：系统与软件工程 生存周期过程 需求工程
- **英文名**：Systems and software engineering — Life cycle processes — Requirements engineering
- **发布 / 实施**：2025-05-30 / 2025-12-01
- **管什么**：**需求工程过程**（怎么获取、验证、管变更）
- **采标**：等同采用 ISO/IEC/IEEE 29148:2018

### 3. GB/T 45630-2025
- **全名**：系统与软件工程 架构描述
- **英文名**：Systems and software engineering — Architecture description
- **发布 / 实施**：2025-04-25 / 2025-11-01
- **管什么**：**架构描述**（要回应利益相关方关切）
- **采标**：等同采用 ISO/IEC/IEEE 42010:2022

### 4. GB/T 38634 系列（软件测试，共 5 份都要）
- **全名**：系统与软件工程 软件测试
- **管什么**：测试概念 / 过程 / 文档 / 技术 / 关键字驱动
- **采标**：等同采用 ISO/IEC/IEEE 29119 系列
- **要这几份**：

| 标准号 | 部分名 | 实施日期 |
|---|---|---|
| GB/T 38634.**1**-2020 | 第1部分：通用概念 | 2020-11-01 |
| GB/T 38634.**2**-2020 | 第2部分：测试过程 | 2020-11-01 |
| GB/T 38634.**3**-2020 | 第3部分：测试文档 | 2020-11-01 |
| GB/T 38634.**4**-2020 | 第4部分：测试技术 | 2020-11-01 |
| GB/T 38634.**5**-2024 | 第5部分：关键字驱动测试 | 2025-05-01 |

- **⚠️ 别拿**：**GB/T 15532-2008**《计算机软件测试规范》——
  这是 2008 年的老标准，网上流传最广但**已被 38634 系列实质覆盖**
- **⚠️ 别拿**：**GB/T 9386-2008**《计算机软件测试文档编制规范》——同上，已被覆盖

### 5. GB/T 25000.51-2016
- **全名**：系统与软件工程 系统与软件质量要求和评价（SQuaRE）
  第51部分：就绪可用软件产品（RUSP）的质量要求和测试细则
- **发布 / 实施**：2016（现行，**2026-09 复核确认未换版**）
- **管什么**：**8 个质量特性**——验收测试大纲的骨架
- **采标**：修改采用 ISO/IEC 25051:2014
- **⚠️ 别拿**：GB/T 25000.51-**2010**（旧版）

### 6. GB/T 8567-2006 ★ 最容易拿的一份
- **全名**：计算机软件文档编制规范
- **英文名**：Specification for computer software documentation
- **发布 / 实施**：2006-03-14 / 2006-07-01
- **管什么**：**文档种类的总目录**（25 种文档的章节结构）
- **采标**：**无**（中国自主制定）→ **所以官方提供免费全文**
- **🆓 免费下载入口**（这份不用买）：
  https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=84C42B6277D2714B7176B10C6E6B1A44
  页面上有「**在线预览**」和「**下载标准**」按钮，需**免费注册登录**
- **⚠️ 别拿**：GB/T 8567-**1988**《计算机软件产品开发文件编制指南》（旧版，标题相似）
- **备注**：它虽 2006 年发布，但**仍是现行最新版**——
  修订计划（计划号 `20020215-T-339`）2005 年下达、周期 60 个月，**至今未完成**

## 三、第三优先：可选参照（国际标准，付费）

**只在需要按"非常小的实体"（≤25 人）轮廓裁剪时参考。**
⚠️ **中国没有采标 ISO/IEC 29110**，它**不能**用来证明"符合国家标准"。

| # | 标准号 | 全名 | 用途 | 参考价 |
|---|---|---|---|---|
| 10 | **ISO/IEC 29110-5-1-2:2025** | Software engineering guidelines for the generic **Basic** profile | B 档（公司/对外交付）参照 | 约 €300 |
| 11 | **ISO/IEC 29110-5-1-1:2025** | Software engineering guidelines for the generic **Entry** profile | A 档（个人/单产品）参照 | 同量级 |
| 12 | ISO/IEC 29110-4-1:2018 | Profile specifications — Generic profile group | **只在要做符合性认证时**才需要 | 约 €108 |

> **❌ 不要买** `29110-2-x` 和 `29110-3-x`——
> 标准原文明确这两块面向**轮廓生产者、评估师、认证机构**，**不是给开发方用的**。
